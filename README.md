🚀 What is Archaeologist?

Archaeologist is an AI-powered personal knowledge agent that helps users recover forgotten information from scattered digital memories.

Instead of requiring an exact filename or keyword, users can describe what they remember.

The system extracts contextual clues such as:

Dates
Organizations
Locations
Amounts
Topics
Document types
Related entities
It then searches available memories, connects related information, and reconstructs the most likely result.

✨ Key Features

🧠 Memory Reconstruction

Describe something you vaguely remember and let the AI reconstruct the likely information.

🔎 Contextual Search

Search using natural language instead of exact filenames.

🔗 Related Memories

Connect related documents and events.

📅 Timeline

Reconstruct the sequence of events surrounding a memory.

🗺️ Knowledge Map

Visualize relationships between organizations, opportunities, documents and events.

🛡️ Evidence & Confidence

Results explain why they match and show supporting evidence.
